# Wireframes Documentation

This folder contains wireframes for the knowledge management application. Each image is annotated with key design rationale and explains how it supports the KM workflow.

---

## 1. Home / Dashboard

**File:** `home_dashboard.png`  
**What to Show:**
- Main navigation (top menu or sidebar)
- Entry points to core features: Search, Add Knowledge, Browse Categories
- Key metrics or quick-access panels (optional)

**Annotations / Rationale:**
- Layout reduces cognitive load by grouping actions logically
- Quick access to frequent tasks supports task-oriented mental models
- Dashboard highlights actionable items and pending work

---

## 2. Core Feature Screen

**File:** `knowledge_entry.png`  
**What to Show:**
- Main KM function: Knowledge entry form or visualization map
- Sections for title, content, tags, categories, attachments
- Action buttons (Save, Cancel, Preview)

**Annotations / Rationale:**
- Screen supports **knowledge externalization** in the SECI model
- Clear separation of metadata and content fields improves information quality
- Stepwise layout guides users to input structured knowledge efficiently

---

## 3. Search / Retrieve Screen

**File:** `search_retrieve.png`  
**What to Show:**
- Search bar, filters, and sorting options
- List of results with preview snippets or tags
- Optional facets for categories or types

**Annotations / Rationale:**
- Retrieval design reflects knowledge taxonomy principles
- Faceted search allows users to explore by type or tag, supporting sense-making
- Result previews enable faster assessment of relevance

---

## 4. User Profile / Settings

**File:** `user_profile.png`  
**What to Show:**
- Personalization options: display name, preferences, notifications
- Role-based access if applicable
- Account or subscription settings

**Annotations / Rationale:**
- Tailors system experience for individual knowledge workers
- Important for tracking contributions, maintaining privacy, and role-based permissions
- Enhances motivation and accountability in KM workflows

---

## 5. Mobile View (Optional +5pts)

**File:** `mobile_view.png`  
**What to Show:**
- Responsive layout of Home or Search screen
- Collapsed menus, stacked panels, and touch-friendly buttons

**Annotations / Rationale:**
- Simplified layout prioritizes core actions for mobile knowledge workers
- Ensures accessibility and usability on smaller screens
- Maintains KM functionality while minimizing scrolling and taps
