# Architecture Decision Record (ADR)

## ADR Template

| Field | Description |
|------|------------|
| **Title** | Short name of the decision (e.g., "Use Firebase for Database") |
| **Date** | When the decision was made |
| **Status** | Decided / Revisited / Superseded |
| **Context** | What problem were you solving? What constraints did you have? |
| **Options Considered** | List 2–3 alternatives you evaluated |
| **Decision** | What you chose and the main reason why |
| **Consequences** | What does this make easier? What does it make harder? |

You need at least 4 ADR entries covering: database choice, hosting/deployment choice, authentication approach (or why you skipped it), and one other significant decision.
